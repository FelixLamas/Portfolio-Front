## 👨‍💻 Sobre Mi Evolución Profesional

Vengo del ecosistema de desarrollo **Fullstack**, lo que me otorgó una base lógica estructurada, dominio de control de versiones y comprensión profunda de arquitecturas de software. 

En mi rol diario como **Analista de Datos & BI**, mi enfoque evolucionó hacia la infraestructura de datos: diseño e implementación de pipelines ETL/ELT, automatización de procesos de ingesta mediante scripts de Python y optimización de consultas en SQL Server.

Actualmente, potencio mi perfil hacia **Data Engineering** aplicando las herramientas del **Modern Data Stack (MDS)** (Apache Airflow, PySpark, dbt, Docker, MinIO/S3, Kafka) y especializándome en la arquitectura Lakehouse con **Microsoft Fabric** (Certificación DP-700).
